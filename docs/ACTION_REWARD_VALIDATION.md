# v12 冻结 v11 特征：奖励首层动作条件读出

新读出能够利用部分已有记忆区分动作结果，但仍有明显误判；概率预测损失没有稳定改善。这是离线读出诊断，不是策略成功率或完整稀疏奖励训练的收敛证据。

## 固定协议

- 冻结 v11 checkpoint：107,200 条交互记录，2,325 次更新。CTM、encoder、策略与价值网络均不更新。
- 从同一前缀构造真实环境的两种初始线索及两种终端动作，共512组、2048条终端分支；原生标签为正确动作+1、错误动作−1。
- 以整组历史划分307/102/103组训练/验证/测试；留出集412条分支，同组线索和动作不跨集合。
- 主要结果用 prior 特征，终端预测不读取终端观测；posterior 特征仅作补充。每个分支使用已冻结的同一个终端潜变量抽样。
- 两种奖励头都从相同 v11 权重开始。新首层将原活动子矩阵复制到两个动作 bank，使初始预测在浮点误差内一致（最大 logit 差约3.8e-6）。
- 两头使用相同实际生产 two-hot NLL、Adam lr=1e-4、clip=1000、eps=1e-8、相同 fresh optimizer state 和同批次。每种3个读出训练种子，batch128，每次最多1000更新；每100更新按验证 NLL 选择权重，之后才评估测试集。
- 所有奖励头参数可训练；新网络只替换第一层，无人工线索、正确性标签输入、特征标准化或额外模块。增加32768个权重，旧头493311、新头526079；本对照检验完整改动，不单独隔离额外参数与显式动作输入的作用。
- 诊断只均衡采样终端±1分支，未包含大量中间0奖励。因此不能把结果当作原生稀疏 replay 上的表现。生产 reward/loss/replay 不变。
